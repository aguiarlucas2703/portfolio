# Lucas Aguiar — Portfolio

Portfólio pessoal de Lucas Aguiar dos Santos, desenvolvedor full-stack.

Este projeto está sendo construído com uma direção visual editorial, inspirada na referência de design compartilhada por Lucas, mas adaptada para apresentar projetos, processo e evolução profissional.

## Status

Em desenvolvimento.

## Direção inicial

- Interface autoral, escura e tipográfica.
- Animações sutis e acessíveis.
- Conteúdo separado da apresentação para facilitar atualizações.
- Projetos e experiências adicionados somente após revisão do autor.

## Stack planejada

- Next.js
- React
- TypeScript
- CSS customizado
- Vitest e React Testing Library
- Playwright
- Vercel

## Qualidade

Antes de cada publicação, o projeto deverá passar por:

- lint;
- verificação de tipos;
- testes de componentes;
- testes de navegação e responsividade;
- build de produção.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
